# 연구 스크립트 (프로덕션 파이프라인과 분리)

실행은 저장소 루트에서: `python3 research/<script>.py`

| 스크립트 | 내용 |
|---|---|
| `fetch_long_history.py` | 2016년~현재 일봉을 `cache/px_long/`에 수집 (약 5분, 12스레드) |
| `long_history_validation.py` | 월간/분기 후보 규칙을 10년 데이터로 검증 (구간 분할·변형 규칙·회피 필터) |
| `monthly_factor_study.py` | 월 1회 매매 기준 지표별 IC와 워크포워드 GBM (3년 패널 필요) |

## 결론 요약 (2026-10 기준)

- **일관되게 유효**: 60일 변동성·회전율·급등일 상위 10% 종목은 이후 20일 -1~2%p, 60일 -3~5%p 열위 (2016~2023에서도 동일). → '회피 필터'.
- **유효하지 않음**: '조용한 매집'(거래량 3~5배↑ + 가격 정체)은 기저율 이하. 후보 규칙(변동성 하위 50% + 52주 고점 -25% 이내 + 거래대금 큰 순 20종목)도 2016~2023에서 초과수익 없음(20/40/60일: -0.6/+0.2/+0.8%p), 2024~2026의 우위는 국면 효과 가능성.
- **한계**: 현재 상장 종목만 포함(생존 편향), 과거 시총은 현재 주식수 근사라 시총 필터 미사용(거래대금 5억 하한만 사용), 비용 0.6% 단순 가정.
- 후속: `monthly_picks.py`의 모의매매(`paper_trades.json`)가 3개월 이상 쌓일 때까지 실자금 투입 보류.
